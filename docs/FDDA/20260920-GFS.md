# 20260920-下载`GFS`

`wget`/`axel`下载`GFS`速度不够理想，因此考虑使用`Globus`进行大数据传输：
```bash
wget https://osdf-director.osg-htc.org/ncar/gdex/d084001/YYYY/YYYYMMDD/gfs.0p25.YYYYMMDDHH.fXXX.grib2
axel -acn8 https://osdf-director.osg-htc.org/ncar/gdex/d084001/YYYY/YYYYMMDD/gfs.0p25.YYYYMMDDHH.fXXX.grib2
```

## 安装注册

使用`conda`进行安装：
```bash
conda install globus-cli
```

使用`GitHub`账号在网页端注册并获取授权码：
```bash
globus login
```

验证登录状态：
```bash
globus whoami
globus session show
```

查看远端文件状态：
```bash
globus ls c4e40965-a024-43d7-bef4-6010f3731b61:/d084001/YYYY/YYYYMMDD/
```

## 配置本地端点

下载安装包并解压：
```bash
wget https://downloads.globus.org/globus-connect-personal/linux/stable/globusconnectpersonal-latest.tgz
tar -xzvf globusconnectpersonal-latest.tgz
```

命令行模式下使用`GitHub`账号在网页端注册并获取授权码（端点名称：`GPU`）：
```bash
./globusconnectpersonal-x.y.z/globusconnect -setup --no-gui
```

获取本机端点`UUID`：
```bash
globus endpoint local-id
```

## 下载数据

配置下载路径权限（默认只能下到家目录）：
```bash
echo "~/data3/GFS/,0,1" >> ~/.globusonline/lta/config-paths
```

后台启动服务：
```bash
./globusconnectpersonal-x.y.z/globusconnect -start &
```

检查连接状态（初始化完成后显示`Globus Online: connected`）：
```bash
./globusconnectpersonal-x.y.z/globusconnect -status
```

批量下载：
```bash
for time in {000..024..3}; do 
  globus transfer \
    c4e40965-a024-43d7-bef4-6010f3731b61:/d084001/YYYY/YYYYMMDD/gfs.0p25.YYYYMMDDHH.f$time.grib2 \
    $(globus endpoint local-id):~/data3/GFS/gfs.0p25.YYYYMMDDHH.f$time.grib2
done
```
或
```bash
for time in {000..024..3}; do
  source="/d084001/${date_str:0:4}/${date_str:0:8}/gfs.0p25.${date_str}.f${time}.grib2"
  destination="~/data3/GFS/gfs.0p25.${date_str}.f${time}.grib2"
  echo "$source $destination" >> tasks
done
globus transfer \
  c4e40965-a024-43d7-bef4-6010f3731b61 $(globus endpoint local-id) \
  --batch tasks --sync-level checksum --preserve-mtime --notify failed
```
其中：
- `--notify off`关闭邮件通知、`--notify failed`只在失败时发送通知；
- `--sync-level checksum`仅当源和目标文件校验和不同才传输；
- `--preserve-mtime`保留文件修改时间戳，方便后续按时间归档。

检查任务状态：
```bash
globus task list
```
