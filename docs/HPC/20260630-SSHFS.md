# 20260630-升级优化`SSHFS`

## 问题描述

`SSHFS 2.x`缺少`max_conns`参数，在并行读取多文件时受单连接限制，因此考虑下载安装`SSHFS 3.x`并对挂载选项作进一步调优。

## 安装过程

安装`libfuse`：
```bash
>>> mkdir -p $HOME/software/fuse && cd $HOME/software/fuse
>>> wget https://github.com/libfuse/libfuse/releases/download/fuse-3.18.2/fuse-3.18.2.tar.gz
>>> tar -xzvf fuse-3.18.2.tar.gz

>>> cd $HOME/software/fuse/fuse-3.18.2
>>> meson setup build --prefix=$HOME/software/fuse -Duseroot=false -Dinitscriptdir= -Dudevrulesdir=$HOME/software/fuse/lib/udev/rules.d
>>> ninja -C build
>>> ninja -C build install
```

对于其中的`meson setup build --prefix=$HOME/software/fuse -Duseroot=false -Dinitscriptdir= -Dudevrulesdir=$HOME/software/fuse/lib/udev/rules.d`：
- `-Duseroot=false`禁止修改所属为`root`；
- `-Dinitscriptdir=`将初始化脚本的安装路径留空，避免写入系统目录；
- `-Dudevrulesdir=$HOME/software/fuse/lib/udev/rules.d`将`udev`规则文件安装到用户目录（该文件实际没用），防止流程因权限不足而失败。

验证安装完成：
```bash
>>> PKG_CONFIG_PATH=$HOME/software/fuse/lib64/pkgconfig pkg-config --modversion fuse3
    3.18.2
```

安装`SSHFS`：
```bash
>>> mkdir -p $HOME/software/sshfs && cd $HOME/software/sshfs
>>> wget https://github.com/libfuse/sshfs/releases/download/sshfs-3.7.6/sshfs-3.7.6.tar.xz
>>> tar -xJvf sshfs-3.7.6.tar.xz

>>> export PKG_CONFIG_PATH="$HOME/software/fuse/lib64/pkgconfig:$CONDA_PREFIX/lib/pkgconfig"

>>> cd $HOME/software/sshfs/sshfs-3.7.6
>>> meson setup build --prefix=$HOME/software/sshfs
>>> ninja -C build
>>> ninja -C build install
```

验证安装完成：
```bash
>>> /public/home/XiaAnRen/software/sshfs/bin/sshfs --version
    SSHFS version 3.7.6
    FUSE library version 3.18.2
    using FUSE kernel interface version 7.45
    fusermount3 version: 3.18.2
```

## 参数调优

使用场景：
- 数十`TB`级别的数据，传输会消耗大量时间与空间（因此不考虑`rsync`）；
- 避免在远端服务器上进行高权限配置（因此不考虑`NFSv4 over SSH`）；
- 在`mgt`上同时读取`mgt`与`admin`两个服务器上的文件进行数据处理并最终保存到`mgt`；
- 远端数据只读；
- 远端文件可能会有变动，但不会太频繁；
- 避免每次数据处理开始前都要重新挂载一次。

### 最终方案

```bash
>>> # mgt
>>> sudo /public/home/XiaAnRen/software/sshfs/bin/sshfs admin:/data /data3/XiaAnRen/admin-data \
>>>      -F /public/home/XiaAnRen/.ssh/config -o IdentityFile=/public/home/XiaAnRen/.ssh/id_rsa -o ro,allow_other,reconnect \
>>>      -o ServerAliveInterval=15,ServerAliveCountMax=3 -o Ciphers=aes128-gcm@openssh.com -o auto_cache,max_conns=8
>>> sudo /public/home/XiaAnRen/software/fuse/bin/fusermount3 -u /data3/XiaAnRen/admin-data
>>> # admin
>>> sudo /public/home/XiaAnRen/software/sshfs/bin/sshfs mgt:/data4 /data/mgt-data4 \
>>>      -F /public/home/XiaAnRen/.ssh/config -o IdentityFile=/public/home/XiaAnRen/.ssh/id_rsa -o ro,allow_other,reconnect \
>>>      -o ServerAliveInterval=15,ServerAliveCountMax=3 -o Ciphers=aes128-gcm@openssh.com -o auto_cache,max_conns=8
>>> sudo /public/home/XiaAnRen/software/fuse/bin/fusermount3 -u /data/mgt-data4
```

对于其中的`-o ServerAliveInterval=15,ServerAliveCountMax=3 -o Ciphers=aes128-gcm@openssh.com -o auto_cache,max_conns=8`：
- `ServerAliveInterval=15,ServerAliveCountMax=3`定期监测并判定失效连接，配合`reconnect`保证自动重连，实现长期稳定挂载；
- `Ciphers=aes128-gcm@openssh.com`更好利用`AES-NI`硬件加速；
- `auto_cache`基于文件时间戳与大小自动失效缓存；
- `max_conns=8`开启并行连接，提升同时读取多个不同文件时的整体吞吐与系统响应。
